Incremental Reading Importer

Connection

Anki must be running with the AnkiConnect add-on installed. AnkiConnect also has to be told to accept requests from this extension: open Tools → Add-ons → AnkiConnect → Config in Anki and add to webCorsOriginList, then restart Anki.

Destination

Space or comma separated. Leave empty for none.

Fields

These must match the fields of the note type above. The defaults match the Incremental Reading add-on's own IR3 note type.

Only if the add-on's priority feature is enabled. Leave as (none) otherwise.

{url} and {date} are replaced, matching the add-on's sourceFormat setting.
